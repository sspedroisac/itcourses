# Data Marts

## 1. O que são Data Marts

Um **Data Mart** é um subconjunto de dados analíticos orientado a uma área, equipe ou assunto específico.

Pode atender vendas, finanças, marketing, operações ou recursos humanos.

---

## 2. Data Mart dependente

Um Data Mart dependente é construído a partir de um Data Warehouse central. Isso favorece padronização, governança e consistência entre áreas.

---

## 3. Data Mart independente

Um Data Mart independente é criado diretamente a partir de fontes operacionais ou arquivos. Pode ser mais rápido no início, mas aumenta risco de duplicação e métricas divergentes.

---

## 4. Benefícios

Data Marts podem:

- simplificar consultas;
- reduzir escopo para uma equipe;
- melhorar performance;
- facilitar criação de dashboards;
- organizar responsabilidades analíticas.

---

## 5. Riscos

Quando cada área cria suas próprias regras, podem surgir definições diferentes para receita, cliente ativo ou venda concluída.

A governança deve manter conceitos comuns e registrar transformações específicas.

---

## 6. Boas práticas

- Definir proprietário do dado;
- Reutilizar dimensões conformadas;
- Documentar métricas;
- Evitar copiar dados sem necessidade;
- Monitorar atualização e qualidade.

---

## 7. Resumo

Data Marts entregam dados analíticos focados em uma área. Quando derivados de uma base governada, ajudam a equilibrar autonomia, performance e consistência.
