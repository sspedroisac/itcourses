# Common Security Terminology

Information Security has many technical terms that are commonly used by security professionals. Understanding these concepts is essential for identifying risks, discussing security problems, and applying effective protection measures.

This lesson introduces some of the most important terms used in cybersecurity and Information Security.

---

# Asset

An **asset** is anything valuable that needs protection.

Assets can include:

- Information
- Hardware
- Software
- Networks
- Systems
- Employees
- Business processes
- Reputation

### Example

A customer database is an important asset because it contains valuable information that could be targeted by attackers.

---

# Threat

A **threat** is anything that has the potential to cause harm to an asset.

Threats can be intentional or accidental.

Examples include:

- Hackers
- Malware
- Phishing emails
- Natural disasters
- Human mistakes
- Insider threats

### Example

A cybercriminal attempting to steal customer information represents a threat to an organization's data.

---

# Vulnerability

A **vulnerability** is a weakness or flaw that can be exploited by a threat.

Vulnerabilities can exist in:

- Software
- Hardware
- Networks
- Configurations
- Security procedures
- Human behavior

Examples:

- Outdated software
- Weak passwords
- Incorrect permissions
- Unpatched systems

### Example

A web application with an outdated library containing a known security flaw has a vulnerability.

---

# Risk

**Risk** is the possibility that a threat will exploit a vulnerability and cause damage.

Risk is commonly influenced by:

- The likelihood of an event occurring.
- The potential impact if it happens.

A simple way to think about risk:

> **Risk = Threat × Vulnerability × Impact**

### Example

A company stores customer data without encryption.

- Threat: An attacker stealing the database.
- Vulnerability: Data is not encrypted.
- Impact: Customer information exposure.

The combination creates a security risk.

---

# Attack

An **attack** is an intentional attempt to exploit a vulnerability and compromise a system, network, or information.

Examples include:

- Phishing attacks
- Password attacks
- Malware infections
- SQL injection
- Denial-of-Service attacks

### Example

An attacker exploiting a vulnerable website to access customer records is performing an attack.

---

# Exploit

An **exploit** is a technique, tool, or code used to take advantage of a vulnerability.

Attackers use exploits to:

- Gain unauthorized access.
- Execute malicious code.
- Steal information.
- Disrupt services.

### Example

A hacker uses a known software vulnerability to gain administrative access to a server.

---

# Security Control

A **security control** is a measure implemented to reduce risks and protect information.

Security controls can be:

### Technical Controls

Implemented through technology.

Examples:

- Firewalls
- Encryption
- Antivirus software
- Multi-Factor Authentication

### Administrative Controls

Related to policies and procedures.

Examples:

- Security policies
- Employee training
- Risk assessments

### Physical Controls

Protect physical assets.

Examples:

- Security cameras
- Door locks
- Access badges

---

# Authentication

**Authentication** is the process of verifying the identity of a user, device, or system.

Common authentication methods include:

- Passwords
- Biometrics
- Security tokens
- Authentication apps

### Example

Entering a password and a verification code to access an account is authentication.

---

# Authorization

**Authorization** determines what an authenticated user is allowed to access or perform.

Authentication answers:

> "Who are you?"

Authorization answers:

> "What are you allowed to do?"

### Example

An employee may be authenticated into a company system but only authorized to access files related to their department.

---

# Encryption

**Encryption** is the process of converting readable information into an unreadable format to prevent unauthorized access.

Only users with the correct key can decrypt and access the original information.

Examples:

- HTTPS communication
- Encrypted storage
- Secure messaging applications

---

# Data Breach

A **data breach** occurs when unauthorized individuals gain access to sensitive information.

Examples:

- Stolen customer databases
- Exposed passwords
- Leaked financial records

Consequences may include:

- Financial losses
- Legal problems
- Reputation damage

---

# Malware

**Malware** is malicious software designed to harm, exploit, or gain unauthorized access to systems.

Common types include:

- Viruses
- Worms
- Trojans
- Ransomware
- Spyware

---

# Social Engineering

**Social Engineering** involves manipulating people into revealing information or performing actions that compromise security.

Attackers often exploit:

- Trust
- Fear
- Urgency
- Curiosity
- Authority

Examples:

- Fake emails
- Phone scams
- Impersonation

---

# Zero-Day Vulnerability

A **zero-day vulnerability** is a security flaw that is unknown to the software vendor or has no available fix.

Because no patch exists, these vulnerabilities can be highly dangerous.

---

# Security Incident

A **security incident** is an event that compromises or threatens the confidentiality, integrity, or availability of information.

Examples:

- Malware infection
- Unauthorized access
- Data leakage
- Account compromise

---

# Incident Response

**Incident Response** is the process of detecting, analyzing, containing, and recovering from security incidents.

A typical incident response process includes:

1. Preparation
2. Detection
3. Analysis
4. Containment
5. Recovery
6. Lessons learned

---

# Key Takeaways

- An **asset** is something valuable that needs protection.
- A **threat** can cause harm to an asset.
- A **vulnerability** is a weakness that can be exploited.
- **Risk** represents the possibility and impact of a security problem.
- **Security controls** reduce risks and protect information.
- **Authentication** verifies identity, while **authorization** defines permissions.
- Understanding security terminology helps professionals communicate and manage security effectively.

---

# Summary

Security terminology provides the foundation for understanding Information Security concepts. By learning terms such as assets, threats, vulnerabilities, risks, and controls, security professionals can better identify problems, evaluate potential impacts, and implement appropriate protections.

These concepts will be used throughout this course as we explore different areas of cybersecurity and information protection.
