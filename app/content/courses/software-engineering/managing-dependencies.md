# Managing Dependencies

Modern software often relies on external libraries, frameworks, and services.

Dependency management is the practice of choosing, updating, and monitoring those dependencies responsibly.

---

## Risks of Dependencies

Dependencies can introduce:

- Security vulnerabilities.
- Breaking changes.
- Licensing issues.
- Performance problems.
- Maintenance risk if a project is abandoned.

External code can become part of your system's risk profile.

---

## Good Dependency Practices

Teams should:

- Prefer well-maintained packages.
- Update dependencies regularly.
- Remove unused packages.
- Review major version upgrades carefully.

This reduces surprises and long-term instability.

---

## Key Takeaways

- Dependencies increase development speed but also introduce risk.
- Dependency choices should be reviewed intentionally.
- Regular updates are safer than rare, massive upgrade efforts.
- Managing third-party code is part of responsible engineering.
