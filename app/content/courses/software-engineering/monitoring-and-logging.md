# Monitoring and Logging

Monitoring and logging help teams understand how software behaves after it is deployed.

They are essential for reliability, troubleshooting, and continuous improvement.

---

## Logging

Logs record events that happen in the system.

Useful logs often include:

- Errors.
- Important state changes.
- Request details.
- Security-relevant events.

Good logs make debugging faster.

---

## Monitoring

Monitoring focuses on system health and performance.

Teams often monitor:

- Error rates.
- Response times.
- Resource usage.
- Availability.
- Queue or job backlogs.

Monitoring helps teams detect issues before users report them.

---

## Key Takeaways

- Logs explain what happened.
- Monitoring shows how the system is performing.
- Both are essential for operating software responsibly.
- Observability improves incident response and long-term reliability.
