# Sorting and Limiting Results

SQL queries often need results in a useful order and in a manageable amount.

Sorting and limiting help shape the final output of a query.

---

## Sorting Results

Sorting is commonly used to:

- Show newest items first.
- Rank scores or sales totals.
- Organize names alphabetically.

Ordered results are often more meaningful to users and systems.

---

## Limiting Results

Limiting results is useful when:

- Showing only the top records.
- Paginating data.
- Reducing unnecessary data transfer.

Returning fewer rows can improve performance and clarity.

---

## Key Takeaways

- Sorting controls the order of query results.
- Limiting controls how many rows are returned.
- Both are important for user-facing applications and analytics.
- Well-shaped query results are easier to use and often more efficient.
