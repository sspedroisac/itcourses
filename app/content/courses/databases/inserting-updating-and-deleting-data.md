# Inserting, Updating, and Deleting Data

Relational databases support not only reading data, but also changing it.

Three core operations are inserting new data, updating existing data, and deleting records.

---

## Insert

Inserting adds new rows to a table.

This is how applications create records such as:

- New users.
- New orders.
- New messages.

---

## Update and Delete

Updating changes existing rows.

Deleting removes rows that are no longer needed or valid.

These operations should be used carefully because mistakes can affect real business data.

---

## Key Takeaways

- Insert adds data.
- Update changes data.
- Delete removes data.
- Data modification commands should be used with care and clear conditions.
