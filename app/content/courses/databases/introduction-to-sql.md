# Introduction to SQL

SQL stands for **Structured Query Language**.

It is the standard language used to interact with relational databases.

---

## What SQL Is Used For

SQL allows you to:

- Read data.
- Insert new records.
- Update existing records.
- Delete records.
- Define database structures.

This makes SQL one of the most important practical skills in database work.

---

## Why SQL Matters

Even when developers use tools such as ORMs, SQL remains important because it reflects how relational data is actually queried and manipulated.

Understanding SQL makes it easier to debug performance issues and reason about data behavior.

---

## Key Takeaways

- SQL is the standard language for relational databases.
- It is used for querying and modifying data.
- SQL knowledge remains valuable even when higher-level tools are used.
- Learning SQL provides direct insight into how relational systems work.
