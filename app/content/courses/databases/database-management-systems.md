# Database Management Systems

A **Database Management System (DBMS)** is software that allows users and applications to create, store, query, and manage data in a database.

The DBMS acts as the layer between raw data and the people or systems using it.

---

## What a DBMS Does

A DBMS commonly provides:

- Data storage.
- Query processing.
- Access control.
- Backup and recovery features.
- Concurrency handling.
- Performance optimization tools.

This makes data management safer and more practical than manual file handling.

---

## Examples

Examples of DBMS products include:

- PostgreSQL.
- MySQL.
- SQLite.
- MongoDB.
- Redis.

Each system has strengths and tradeoffs.

---

## Key Takeaways

- A DBMS is the software used to manage databases.
- It provides essential capabilities beyond simple storage.
- Different DBMS products support different data models and workloads.
- Choosing a DBMS is an engineering decision with long-term impact.
