# Selecting Data with SELECT

The `SELECT` statement is used to retrieve data from a relational database.

It is one of the most common and important SQL commands.

---

## Basic Idea

`SELECT` allows you to choose:

- Which columns to return.
- Which table to read from.
- Whether additional filters or ordering should apply.

This makes it the foundation of most data analysis and application queries.

---

## Why It Matters

Good use of `SELECT` helps engineers retrieve only the data they need.

Fetching too much data can waste time, memory, and network resources.

---

## Key Takeaways

- `SELECT` is used to read data from tables.
- It can return specific columns or broader result sets.
- Efficient queries begin with asking for only what is needed.
- Understanding `SELECT` is essential for practical SQL work.
