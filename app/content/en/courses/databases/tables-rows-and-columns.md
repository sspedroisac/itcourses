# Tables, Rows, and Columns

Relational databases organize data into tables.

Each table contains rows and columns that define how information is stored.

---

## Tables

A table represents a category of information, such as:

- Users.
- Products.
- Orders.
- Payments.

Each table groups records of the same general type.

---

## Rows and Columns

A **row** represents one individual record.

A **column** represents one property of that record.

For example, a users table might contain columns such as name, email, and signup date.

---

## Why This Structure Matters

This tabular structure makes data easier to:

- Search.
- Sort.
- Filter.
- Relate to other tables.

It also supports consistency and predictable query behavior.

---

## Key Takeaways

- Tables organize related records.
- Rows store individual entries.
- Columns store attributes of each entry.
- These concepts are fundamental to relational databases.
