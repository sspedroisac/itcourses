# Choosing Data Types

Every column in a relational schema must store a particular kind of value.

Choosing appropriate data types is important for correctness, efficiency, and clarity.

---

## Why Data Types Matter

Good data types help with:

- Validation.
- Storage efficiency.
- Query behavior.
- Indexing.
- Readability of the schema.

Poor choices can create bugs, wasted space, or confusing conversions.

---

## Examples

Teams often choose between types such as:

- Integer.
- Decimal.
- Boolean.
- Date and time.
- Text.

Each type should reflect the meaning of the stored value.

---

## Key Takeaways

- Data types communicate what a column is meant to hold.
- Good type choices improve correctness and efficiency.
- Schemas become easier to understand when types match real meaning.
- Careful type selection prevents avoidable data issues later.
