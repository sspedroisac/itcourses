# Primary Keys and Foreign Keys

Keys are essential for identifying records and connecting related tables.

Two of the most important key types are primary keys and foreign keys.

---

## Primary Keys

A primary key uniquely identifies each row in a table.

Examples include:

- A user ID.
- An order number.
- A product SKU.

Without a reliable unique identifier, records become difficult to manage safely.

---

## Foreign Keys

A foreign key connects one table to another by referencing a primary key elsewhere.

For example, an orders table may store a user ID that points to a row in the users table.

This creates relationships between records.

---

## Why Keys Matter

Keys help databases:

- Prevent duplicate ambiguity.
- Connect related data.
- Enforce integrity rules.
- Support efficient querying.

---

## Key Takeaways

- Primary keys uniquely identify rows.
- Foreign keys link related tables.
- Keys are essential for relational modeling and integrity.
- Good schema design starts with clear identifiers.
