# Common Database Terminology

Database work involves a shared vocabulary.

Learning the common terms makes documentation, discussions, and tooling easier to understand.

---

## Common Terms

Some foundational terms include:

- **Table**: A structured collection of related records.
- **Row**: One record in a table.
- **Column**: One attribute stored for each row.
- **Schema**: The structural definition of the database.
- **Query**: A request to read or change data.
- **Index**: A structure that speeds up data retrieval.
- **Transaction**: A group of operations treated as a single unit.

---

## Why Terminology Matters

Much confusion in database work comes from unclear language.

When teams use consistent terminology, it becomes easier to discuss:

- Data models.
- Query problems.
- Performance issues.
- Migration plans.

---

## Key Takeaways

- Database terminology provides a common language for engineering work.
- Terms such as table, schema, query, and index appear constantly in practice.
- Learning these concepts early makes deeper topics easier to understand.
- Clear vocabulary improves team communication.
