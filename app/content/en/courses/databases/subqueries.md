# Subqueries

A subquery is a query written inside another query.

It allows one query to depend on the result of another.

---

## Why Subqueries Are Useful

Subqueries help when you need to:

- Compare values against a derived result.
- Filter based on related data.
- Build more complex logic in manageable steps.

They can be useful, but they should be written carefully for clarity and performance.

---

## Tradeoffs

Some subqueries are easy to understand.

Others can become hard to read or may be slower than alternative approaches such as joins or common table expressions.

---

## Key Takeaways

- Subqueries place one query inside another.
- They are useful for layered logic and derived conditions.
- Clarity and performance should both be considered.
- Good query design chooses the simplest correct structure.
