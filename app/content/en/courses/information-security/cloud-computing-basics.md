# What Is Cloud Computing?

**Cloud computing** is the delivery of computing services over the Internet.

Instead of purchasing and maintaining physical servers and infrastructure, users can access computing resources on demand from cloud providers.

These resources may include:

- Computing power
- Data storage
- Databases
- Networking
- Software applications
- Artificial intelligence services

Cloud computing allows individuals and organizations to use technology without owning the underlying hardware.

---

# Why Cloud Computing Is Important

Cloud computing has transformed how organizations build and operate IT systems.

Benefits include:

- Reduced infrastructure costs
- Faster deployment of services
- High scalability
- Improved flexibility
- Global availability
- Easier collaboration

Today, many websites, mobile applications, and business systems rely on cloud services.

---

# Key Characteristics of Cloud Computing

Cloud computing is commonly defined by several essential characteristics.

## On-Demand Self-Service

Users can provision computing resources whenever needed without requiring direct assistance from the provider.

Examples include:

- Creating a virtual machine
- Expanding storage capacity
- Launching a database

---

## Broad Network Access

Cloud services are available over the Internet and can be accessed from various devices, including:

- Computers
- Smartphones
- Tablets

---

## Resource Pooling

Cloud providers share computing resources among many customers.

This approach is known as **multi-tenancy**.

Although resources are shared, each customer's data remains logically isolated.

---

## Rapid Elasticity

Cloud resources can scale up or down quickly based on demand.

For example:

- An online store can increase computing capacity during a major sale.
- Resources can be reduced afterward to lower costs.

---

## Measured Service

Cloud providers monitor resource usage.

Customers typically pay only for what they consume.

Examples include charges based on:

- Storage used
- Computing time
- Network traffic

---

# Cloud Service Models

Cloud services are commonly grouped into three main models.

## Infrastructure as a Service (IaaS)

IaaS provides virtualized computing infrastructure.

The cloud provider manages the physical hardware, while the customer manages the operating system and applications.

Examples of resources include:

- Virtual machines
- Storage
- Networking

Customers have significant control over the environment.

---

## Platform as a Service (PaaS)

PaaS provides a platform for developing and deploying applications.

The provider manages:

- Infrastructure
- Operating systems
- Runtime environments

Developers focus primarily on building and deploying applications.

---

## Software as a Service (SaaS)

SaaS delivers complete software applications through the Internet.

Users access the software using a web browser or mobile application.

Examples include:

- Email services
- Online document editors
- Customer relationship management (CRM) systems

The cloud provider manages nearly all aspects of the service.

---

# Comparing the Service Models

| Responsibility   | IaaS     | PaaS     | SaaS     |
| ---------------- | -------- | -------- | -------- |
| Applications     | Customer | Customer | Provider |
| Data             | Customer | Customer | Customer |
| Operating System | Customer | Provider | Provider |
| Infrastructure   | Provider | Provider | Provider |

As you move from IaaS to SaaS, the provider manages more of the environment.

---

# Cloud Deployment Models

Organizations choose different deployment models depending on their needs.

## Public Cloud

Infrastructure is owned and operated by a third-party cloud provider.

Resources are shared among multiple customers.

Advantages include:

- Lower cost
- High scalability
- Global availability

---

## Private Cloud

Infrastructure is dedicated to a single organization.

Benefits include:

- Greater control
- Enhanced customization
- Improved regulatory compliance for certain environments

Private clouds generally require higher costs and management effort.

---

## Hybrid Cloud

A hybrid cloud combines public and private cloud environments.

Organizations may keep sensitive workloads in a private cloud while using the public cloud for less sensitive or highly scalable workloads.

---

# Shared Responsibility Model

One of the most important cloud security concepts is the **Shared Responsibility Model**.

Security responsibilities are divided between the cloud provider and the customer.

Generally:

**Cloud Provider Responsibilities**

- Physical data centers
- Networking infrastructure
- Physical servers
- Hardware maintenance

**Customer Responsibilities**

- User accounts
- Passwords
- Access permissions
- Data protection
- Application security
- Security configuration

Using cloud services does **not** eliminate the customer's responsibility for security.

---

# Cloud Security Benefits

Cloud computing offers several security advantages.

Examples include:

- Professional data center security
- Automatic backups
- High availability
- Disaster recovery capabilities
- Built-in encryption options
- Continuous security updates

Large cloud providers invest heavily in protecting their infrastructure.

---

# Cloud Security Challenges

Despite its benefits, cloud computing introduces new security challenges.

Examples include:

- Misconfigured cloud resources
- Weak access controls
- Exposed storage buckets
- Compromised user accounts
- Insecure APIs
- Data privacy concerns

Many cloud security incidents result from configuration errors rather than failures by the cloud provider.

---

# Best Practices

To improve cloud security:

- Enable Multi-Factor Authentication (MFA).
- Use the Principle of Least Privilege.
- Encrypt sensitive data.
- Keep cloud resources properly configured.
- Monitor user activity.
- Regularly review access permissions.
- Back up important data.
- Keep applications updated.
- Understand your responsibilities under the Shared Responsibility Model.

---

# Why Cloud Computing Matters for Information Security

Cloud computing is now a fundamental part of modern IT infrastructure.

Security professionals must understand how cloud environments differ from traditional on-premises systems.

Protecting cloud resources requires:

- Strong identity management
- Secure configurations
- Continuous monitoring
- Proper access control
- Shared responsibility between providers and customers

Understanding these concepts is essential for securing today's digital services.

---

# Key Takeaways

- Cloud computing delivers computing services over the Internet.
- Its key characteristics include on-demand access, scalability, and resource sharing.
- The three primary service models are IaaS, PaaS, and SaaS.
- Cloud deployment models include public, private, and hybrid clouds.
- Security responsibilities are shared between the cloud provider and the customer.
- Cloud computing offers many security benefits but also introduces new security challenges.
- Proper configuration, access control, and monitoring are essential for securing cloud environments.
