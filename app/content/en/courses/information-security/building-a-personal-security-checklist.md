# Building a Personal Security Checklist

## Learning Objectives

By the end of this lesson, you will be able to:

- Understand the importance of having a personal security checklist.
- Identify essential cybersecurity practices for everyday life.
- Create habits that reduce security risks.
- Apply security measures to protect accounts, devices, and personal information.
- Maintain and improve your personal security over time.

---

# What Is a Personal Security Checklist?

A **Personal Security Checklist** is a collection of cybersecurity practices that individuals can follow to protect their information, accounts, devices, and digital identity.

It works as a practical guide to ensure important security measures are not forgotten.

A checklist helps transform security from something reactive into a daily habit.

---

# Why Have a Personal Security Checklist?

Cybersecurity threats are constantly changing.

A personal security checklist helps individuals:

- Reduce the risk of account compromise.
- Protect personal information.
- Prevent malware infections.
- Improve online privacy.
- Respond faster when problems occur.

Small security improvements can significantly reduce exposure to cyber threats.

---

# Account Security Checklist

Accounts are one of the most common targets for attackers.

## Use Strong Passwords

Create passwords that are:

- Long.
- Unique.
- Difficult to guess.
- Different for every account.

Avoid:

- Reusing passwords.
- Using personal information.
- Sharing passwords with others.

---

## Use a Password Manager

A password manager helps:

- Generate strong passwords.
- Store credentials securely.
- Reduce password reuse.
- Simplify account management.

Using a password manager is safer than relying on memory or storing passwords in insecure places.

---

## Enable Multi-Factor Authentication (MFA)

MFA adds an additional security layer beyond passwords.

Examples:

- Authentication applications.
- Security keys.
- Biometric verification.

Even if a password is stolen, MFA can prevent unauthorized access.

---

## Review Account Activity

Regularly check:

- Login history.
- Connected devices.
- Security notifications.
- Account permissions.

Unexpected activity may indicate account compromise.

---

# Device Security Checklist

Your devices store valuable personal information.

## Keep Software Updated

Regular updates fix security vulnerabilities.

Keep updated:

- Operating systems.
- Applications.
- Browsers.
- Security software.

---

## Use Screen Locks

Protect devices with:

- Strong passwords.
- PINs.
- Biometrics.

A lost device should not provide easy access to your information.

---

## Install Software Carefully

Before installing applications:

- Download from trusted sources.
- Check permissions requested.
- Avoid pirated software.
- Remove applications you no longer use.

Unknown software may contain malware.

---

## Enable Device Protection

Use available security features:

- Device encryption.
- Antivirus protection.
- Firewall settings.
- Automatic updates.

---

# Internet Safety Checklist

Online activity creates many security risks.

## Be Careful With Links

Before clicking:

- Verify the sender.
- Check the destination.
- Be suspicious of urgent requests.

Avoid clicking unknown links from:

- Emails.
- Messages.
- Social networks.

---

## Verify Websites

Before entering sensitive information:

- Check the website address.
- Confirm the organization.
- Look for HTTPS.
- Avoid suspicious pages.

Attackers often create fake websites that look legitimate.

---

## Protect Personal Information

Avoid sharing unnecessary details online.

Be careful with:

- Home address.
- Phone number.
- Identification information.
- Travel plans.
- Personal routines.

Information shared publicly may be used for social engineering.

---

# Email Security Checklist

Email remains one of the most common attack methods.

Practice safe email habits:

- Do not open unexpected attachments.
- Verify suspicious requests.
- Check sender addresses carefully.
- Report phishing attempts.
- Avoid replying to suspicious messages.

---

# Social Media Security Checklist

Social networks contain valuable personal information.

Protect yourself by:

- Reviewing privacy settings.
- Limiting public information.
- Avoiding oversharing.
- Enabling MFA.
- Checking suspicious friend or follower requests.

Attackers often use social media for reconnaissance.

---

# Wi-Fi Security Checklist

Wireless networks can expose users to risks.

## Home Wi-Fi

Improve security by:

- Changing default router passwords.
- Using strong Wi-Fi passwords.
- Keeping router firmware updated.
- Using modern encryption standards.

---

## Public Wi-Fi

When using public networks:

- Avoid accessing sensitive accounts when possible.
- Use trusted VPN solutions when appropriate.
- Disable automatic connections.
- Avoid transferring confidential information.

---

# Data Protection Checklist

Protect important information by:

## Backing Up Data

Maintain backups of:

- Documents.
- Photos.
- Important files.

Follow the 3-2-1 backup principle:

- 3 copies of data.
- 2 different storage types.
- 1 copy stored separately.

---

## Encrypt Sensitive Information

Encryption helps protect data from unauthorized access.

Use encryption for:

- Devices.
- Backups.
- Sensitive files.

---

## Delete Data Securely

When disposing of information:

- Permanently delete digital files.
- Reset devices before selling.
- Destroy sensitive documents properly.

---

# Privacy Checklist

Improve your digital privacy by:

- Reviewing application permissions.
- Limiting unnecessary data sharing.
- Reading privacy settings.
- Removing unused accounts.
- Checking data exposure regularly.

---

# Physical Security Checklist

Cybersecurity also involves protecting physical access.

Good practices include:

- Locking devices when away.
- Protecting documents.
- Avoiding leaving devices unattended.
- Reporting lost equipment quickly.

Physical access can lead to digital compromise.

---

# Incident Response Checklist

Knowing what to do after a security problem occurs is important.

If an account or device is compromised:

1. Disconnect affected devices if necessary.
2. Change compromised passwords.
3. Enable MFA.
4. Review account activity.
5. Contact relevant organizations.
6. Report the incident.

Fast action can reduce damage.

---

# Regular Security Review

Security should be reviewed periodically.

Perform regular checks:

- Review account permissions.
- Update passwords when necessary.
- Remove unused accounts.
- Update devices.
- Review privacy settings.
- Test backups.

Security is an ongoing process.

# Building a Security Mindset

A strong security posture is not created by a single tool or action.

It comes from consistent habits:

- Thinking before clicking.
- Questioning unexpected requests.
- Protecting information.
- Keeping systems updated.
- Staying informed.

Security awareness turns everyday users into an important line of defense.

---

# Why a Personal Security Checklist Matters

Cybersecurity is a shared responsibility.

A personal security checklist helps individuals:

- Protect their digital identity.
- Reduce exposure to threats.
- Build safer technology habits.
- Respond effectively to incidents.
- Maintain control over their information.

By following simple security practices consistently, anyone can significantly improve their protection in the digital world.
